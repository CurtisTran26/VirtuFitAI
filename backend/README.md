# Backend local setup

Requires Python 3.11+ and PostgreSQL 15+. Create a database named `virtufit`, apply the migration and seed from `database/README.md`, then set `DATABASE_URL` in the shell. Install each API's requirements in its own virtual environment. From `backend/app-api`, run `uvicorn app.main:app --reload --port 8000`; from `backend/management-api`, run `uvicorn app.main:app --reload --port 8001`. Both APIs read environment variables directly; uvicorn does not load `.env` automatically. Set `CORS_ORIGINS` to the web origins and `SESSION_TTL_HOURS` as needed.

`OTP_DEBUG=true` is for local integration only. The production SMS provider is not configured in this repository, so OTP delivery needs an approved provider adapter before deployment. Seed creates roles only; provision the first admin out of band by setting `VIRTUFIT_ADMIN_PHONE`, `VIRTUFIT_ADMIN_NAME`, and `VIRTUFIT_ADMIN_PASSWORD` then running `python ../../database/scripts/create_admin.py` from `backend/management-api`. Use a unique phone and a password of at least 16 characters, then remove it from the environment. Create staff accounts through the admin API. Do not place account passwords in SQL seeds.
